# Barbería El Patrón — Página web de ejemplo

Página web de muestra para una barbería, hecha para mostrar cómo puede verse el sitio de un negocio local.

🔗 **Ver en vivo:** https://pulsomotionstudio-create.github.io/demo-barberia/

## Qué incluye
- Portada con llamado a la acción
- Carta de servicios con precios
- Galería de fotos
- Ubicación, mapa y horario (con aviso de abierto o cerrado)
- Formulario de reserva que abre WhatsApp con el mensaje listo
- Botón flotante de WhatsApp
- Diseño adaptado a celular y computador

## Tecnología
HTML, CSS y JavaScript, sin dependencias. Publicada gratis con GitHub Pages.

> Es un sitio de demostración: el negocio, los precios, el número y los testimonios son de ejemplo.
